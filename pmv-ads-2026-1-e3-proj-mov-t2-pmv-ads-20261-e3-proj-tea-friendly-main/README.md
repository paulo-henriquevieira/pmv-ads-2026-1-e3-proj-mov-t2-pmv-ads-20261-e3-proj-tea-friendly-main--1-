# TEA Friendly

`CURSO: ANÁLISE E DESENVOLVIMENTO DE SISTEMAS - PUCMINAS`

`Desenvolvimento de uma Aplicação Móvel em um Ambiente de Negócio`

`Eixo 3 - TURMA 2 - 1/2026`


  Este projeto propõe o desenvolvimento de uma aplicação digital voltada para auxiliar pessoas com Transtorno do Espectro Autista (TEA), bem como seus pais e cuidadores, na identificação de estabelecimentos mais preparados para atender às suas necessidades sensoriais e sociais. 
  
  A plataforma permitirá a busca e o compartilhamento de informações sobre locais considerados mais acessíveis e acolhedores, possibilitando que os usuários avaliem ambientes, consultem características sensoriais dos espaços e tomem decisões mais seguras ao planejar atividades fora de casa.
