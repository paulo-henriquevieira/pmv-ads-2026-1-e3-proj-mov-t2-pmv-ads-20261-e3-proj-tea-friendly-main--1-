
# Projeto de Interface

## Diagrama de Fluxo

### Fluxo de Navegação e Cadastro da Aplicação TEA Friendly 

O fluxo da aplicação inicia quando a pessoa abre o aplicativo e escolhe o tipo de acesso: **usuário** ou **estabelecimento**.

No fluxo de **usuário**, caso já possua conta, realiza login e acessa normalmente as funcionalidades da plataforma. Caso não possua conta, pode entrar como **visitante**, tendo permissão para buscar e visualizar os estabelecimentos cadastrados, mas sem poder comentar, avaliar ou favoritar locais.

No fluxo de **estabelecimento**, caso já exista conta, o responsável realiza login. Caso ainda não tenha cadastro, deve preencher os dados do estabelecimento e enviá-los para análise. Após isso, o cadastro fica com status **pendente**, aguardando validação de um **administrador**. Se aprovado, o estabelecimento passa a ficar disponível nas buscas do aplicativo. Se reprovado, retorna para ajuste e novo envio.

Esse fluxo garante **facilidade de acesso para famílias e usuários**, ao mesmo tempo em que mantém **controle e confiabilidade das informações dos estabelecimentos cadastrados.**
